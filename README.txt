LAYAN BARGOUTHI — MECHANICAL ENGINEERING PORTFOLIO

This folder is a complete static website ready for GitHub Pages.

OPEN LOCALLY
1. Keep this entire folder together.
2. Double-click index.html.
3. All images, styling, project pages, contact information, and certifications use relative paths and should work locally.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository (for example: layanbargouthi.github.io).
2. Upload the CONTENTS of this folder so index.html is at the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the main branch and / (root), then Save.
6. GitHub will provide the public site URL after deployment.
